# Research

Raw meeting notes and transcripts land here, one file per meeting: `YYYY-MM-DD-{slug}.md`. Use subfolders by topic once you have more than ~20 files.

Each file starts with:

```
# {Title}
**Date:** YYYY-MM-DD
**Source:** Granola / Zoom / manual notes
**Participants:** ...
```

then a summary, then `## Full Transcript`. Run `/synthesize` after adding files.
